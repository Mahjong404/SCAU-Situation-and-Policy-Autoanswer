# SCAU 形势与政策 自动答题

超星学习通《形势与政策》课程自动化工具，基于 Playwright 浏览器自动化。
支持视频自动播放、题目自动作答，启动前可交互式修改设置。

## 环境要求

- Windows 系统（Edge 浏览器已预装）
- Python 3.12+

```bash
pip install playwright
```

无需 `playwright install`，默认使用系统 Edge 浏览器 (`channel="msedge"`)。

## 使用

```bash
python main.py
```

首次运行会自动生成 `real_data/account.json` 和 `real_data/settings.json`（模板参考 `data/` 下同名文件）。

启动时打印当前设置摘要，询问是否修改：

```
当前设置：
  账号: (空)
  密码: (空)
  课程URL: (空)
  浏览器: msedge
  倍速: 2.0x
  静音: 是

修改设置？(y/N):
```

回车跳过直接执行，输入 `y` 逐项修改：

| 项目 | 说明 |
|------|------|
| 账号/密码/URL | 超星学习通登录凭据和目标课程链接 |
| 浏览器 | Edge / Chrome / Chromium |
| 播放倍速 | 默认 2x，课程锁定倍速时自动回退 |
| 静音播放 | 默认静音 |

账号未填写完整时程序退出并提示先配置。

## 题库

题库入口：[题库目录](<question bank/>) · [题库说明](<question bank/README.md>) · [学期索引](<question bank/index.json>)。

### 已整理学期

| 学期 | 对应时间 | 完整可用题目 | 入口 |
|---|---|---:|---|
| `2025-2026-2` | 2025—2026学年第二学期 | 60题 | [查看题库](<question bank/2025-2026-2/questions.json>) |
| `2026-2027-1` | 2026—2027学年第一学期 | 69题 | [查看题库](<question bank/2026-2027-1/questions.json>) · [全部70题答案](<question bank/2026-2027-1/answers.json>) |

学期目录统一使用 `yyyy-yyyy-x`：两个年份表示学年，`x=1` 为第一学期，`x=2` 为第二学期。按课程所属学期选择，不要仅按当前日期选择，也不要混用不同学期题库。

`2026-2027-1` 共整理70道不同题目，其中第43题答案为 `ABCD`，但题干部分遮挡，暂未纳入完整题库。公开仓库只保留规范题库、校验摘要及处理脚本；截图、原始OCR、笔记链接和逐题来源记录保留在本地。

### 选择学期

当前程序仍固定读取 `data/questions.json`，尚未提供启动时的学期选择。使用前，在克隆仓库的根目录将目标学期题库复制到该位置。例如选择2026—2027学年第一学期：

```powershell
# 先备份当前使用的题库
Copy-Item 'data/questions.json' 'data/questions.backup.json'

# 将目标学期完整题库设为当前题库
Copy-Item 'question bank/2026-2027-1/questions.json' 'data/questions.json' -Force
```

如需选择上一学年第二学期，将复制源改为 `question bank/2025-2026-2/questions.json`。确认课程与学期一致后，再按上方“使用”步骤启动程序。题库中没有匹配题目时，现有答题模块会停止；`answers.json` 是答案汇总，不能代替四字段完整题库。

### 题目格式

`data/questions.json` 使用以下格式：

```json
{
  "type": "单选题|多选题|判断题",
  "question": "题目文本",
  "options": ["选项A", "选项B", ...],
  "answer": "A" | "AB" | "√" | "X"
}
```

## 流程

四模块管道依次执行：

```
setup → auto_sign_in → auto_course → auto_answer
```

### setup — 启动前设置

交互式确认/修改账号凭据、浏览器、倍速、静音等设置。详见上方「使用」部分。

### auto_sign_in — 自动登录

注入脚本防止超星弹窗检测，根据设置选用的浏览器和凭据登录。

### auto_course — 视频自动播放

- 遍历课程目录树，定位未完成的叶子节点
- 按顺序播放每个视频 iframe，自动设置倍速 + 静音
- 倍速设置三级回退：菜单点击 → 检测 playbackRate → 直接赋值
- 关闭"记笔记"提示弹窗，避免遮挡控制按钮
- 检测视频结束状态后进入下一个
- 最多 100 轮遍历上限，全部完成自动退出

### auto_answer — 自动答题

- 进入三层嵌套 iframe 定位题目区域
- 提取 base64 TTF 字体解码混淆文字
- 题目匹配：先精确匹配，失败则模糊匹配（阈值 0.92）
- 选项匹配：精确 → 模糊（阈值 0.85）
- 支持单选题、多选题、判断题，完成后自动保存

## 后续更新计划

以下为大致实施顺序，尚未完成的功能不代表当前版本已经支持，暂不承诺具体发布日期。

2. **增加学期选择**：启动时列出可用学期和题目数量，保存选择，直接读取对应目录，省去手动覆盖 `data/questions.json`。

5. **完善分发与维护**：在流程稳定后提供Windows安装包，补充依赖检查、错误提示和升级说明。
